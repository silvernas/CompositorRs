# Compositor

Adobe Photoshop 太贵了，而像 GIMP 这样的工具对我来说又不够顺手，难以保持专注的工作状态。这正是我开发 Compositor 的原因。

我们的目标是打造一款功能完备、完全免费且开源的图像编辑器。我平时使用 Photoshop 进行合成与后期处理，因此 Compositor 围绕这一工作流构建——提供制作像素级精确成品图像所需的各种工具。

由于它是开源的，你可以下载 Xcode 工程，自由添加、删除或修改任何功能，以适配你自己的工作流。

## 功能特性

### 图层
- 图层与文件夹，支持混合模式与不透明度
- 图层蒙版：可绘制、填充、反相、模糊及羽化；可链接或取消链接，以独立变换蒙版
- 剪贴蒙版与文件夹蒙版
- 调整图层：色相/饱和度、色阶、曲线、曝光、渐变映射与颗粒
- 向下合并、合并图层与合并组（⌘E）
- 复制、行内重命名、拖拽排序与嵌套；按住 Option 拖拽可复制
- 在打开的项目之间拖拽图层

### 变换
- 非破坏性的移动、缩放、旋转与翻转——无论图像被缩到多小，都保留完整分辨率
- 自由变形（⌘-拖拽控制点），按住 Shift 可锁定到某一轴
- 同时变换多个图层，或整个文件夹
- 吸附到画布与图层边缘及中心，并支持参考线
- 位置、尺寸、缩放与角度的精确数值，可用方向键微调
- 翻转图层与翻转画布，支持水平与垂直方向

### 选区
- 矩形与椭圆选框、自由与多边形套索，以及魔棒
- 向选区添加或从中减去、移动选区轮廓，或移动并复制选区内像素
- 将图层的像素或蒙版载入为选区
- 内容识别填充，还可将图像延伸至其边缘之外

### 绘画与修饰
- 画笔，支持大小、硬度与不透明度，按住 Shift 可绘制直线
- 污点修复画笔（内容识别）
- 仿制图章，可对齐或不对齐，采样单个图层或全部图层
- 模糊工具，可用于像素或蒙版
- 渐变工具与形状工具（矩形、圆角矩形与椭圆）
- 文字工具（T）：在可拖拽、可调整大小的段落框中进行行内多行编辑；字体、大小、颜色、对齐与间距在工具头部设置；可变换文字并将其用作剪贴蒙版
- 吸管工具与完整的取色器

### 调整与滤镜
- 色阶（含自动）、曲线、色相/饱和度、曝光、渐变映射、颗粒与反相
- 高斯模糊与动感模糊，可扩散至图层边缘之外
- 添加杂色、镜头校正与移除背景
- 实时预览，存在选区时仅限于选区范围

### 画布与文件
- 以标签页打开多个项目
- 裁剪支持吸附，按住 Option 进行对称裁剪
- 画布大小与图像大小
- 缩小时高质量清晰下采样，放大时显示像素网格
- 导入 JPEG、PNG、HEIC 与 TIFF——包括拖入的截图以及来自其他应用的图像
- 导出 JPEG 时提供实时预览（⇧⌥⌘S）；合并拷贝
- 全程采用 Photoshop 风格的键盘快捷键

## 环境要求

- macOS 26
- Xcode 26（用于从源码构建）

## 构建

打开 `Compositor.xcodeproj` 并运行 **Compositor** 方案（scheme）。

## 发布

`scripts/release.sh` 会构建 Release 版本，使用 Developer ID 进行签名、公证并装订（staple），最后打包为 `dist/Compositor-<版本号>.dmg`。

脚本需要以下资源，且均需存放于本仓库之外：

- 登录钥匙串中的 **Developer ID Application** 证书
- 通过 `xcrun notarytool store-credentials "compositor-notary" …` 保存的公证凭据
- [`create-dmg`](https://github.com/create-dmg/create-dmg)（`brew install create-dmg`）
